### What I built

- Constraint-driven timetable generation engine
- Genetic Algorithm optimization pipeline
- Custom fitness function
- Clash minimization
- Resource-overload minimization
- Student idle-time optimization
- Crossover and mutation
- Tournament selection
- FastAPI backend integrated with Supabase
- **95%+ reduction in scheduling time**
